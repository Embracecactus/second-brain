# 模块化可拆卸摄像头系统

## 项目概述

一个模块化可拆卸的AI摄像头系统，采用核心板+外设模块的架构，以RV1126B为AI核心芯片，支持USB和电池双路供电，电源模块v5.1实现100%无缝切换（<10μs），总硬件成本约￥30.5。当前处于硬件设计阶段，电源模块设计已完成，核心板设计进行中。

## 技术栈

| 领域 | 技术/器件 | 说明 |
|------|----------|------|
| **主控芯片** | Rockchip RV1126B | AI视觉处理器，USB 2.0 ONLY（非3.0） |
| **电源切换** | LTC4412 | 理想二极管控制器，单芯片双MOSFET控制 |
| **升压转换** | TPS61022 | 3.7V→5V @ 3A，10A开关电流，效率>96% |
| **降压转换** | SY8113 | 5V→3.3V @ 2A |
| **充电管理** | TP4056 | 线性充电IC，500mA可调 |
| **电量检测** | BQ27421 | I2C电量计（可选） |
| **功率MOSFET** | AO3407A×2 | P-MOSFET，SOT-23，Rds(on)<50mΩ |
| **结构设计** | 铝合金6063 / PLA 3D打印 | 三明治分层结构，95×85×30mm |
| **EDA工具** | EasyEDA专业版 | 原理图与PCB设计 |
| **PCB** | 2层板 | 30×50mm电源模块 |

## 架构与关键设计

### 系统架构

```
┌────────────────────────────────────────────┐
│          外设模块区（可插拔）                 │
│  摄像头 │ 显示屏 │ 按键 │ WiFi │ 天线       │
├────────────────────────────────────────────┤
│          核心板 (RV1126B) 55×50mm           │
│          80pin 2.0mm排针座连接              │
├────────────────────────────────────────────┤
│          电源模块 50×40mm                    │
│  USB 5V ←→ LTC4412 ←→ 电池3.7V             │
│  TPS61022升压 → SY8113降压                  │
└────────────────────────────────────────────┘
```

### 电源系统v5.1核心设计（100%无缝切换）

**关键创新：单LTC4412控制双路MOSFET**

```
USB 5V → [PTC+TVS保护] → Q1(AO3407A) ←── LTC4412 STAT控制
                              ↓
                          VCC5V0_SYS ←── LTC4412 SENSE检测
                              ↑
电池3.7V → TPS61022升压 → Q2(AO3407A) ←── LTC4412 GATE控制
```

- **GATE和STAT互补控制**：不会同时导通，保证路径隔离
- **切换阈值**：SENSE > VIN + 20mV 时切换到USB，SENSE < VIN - 30mV 时切换到电池
- **切换时间**：<10μs，电压波动<50mV
- **无需I2C配置**：上电即工作，消除了v3.x BQ25895方案的启动死锁风险

### 80pin扩展接口定义

核心板通过80pin 2.0mm排针座引出全部信号：

| Pin范围 | 功能 | 说明 |
|---------|------|------|
| 1-8 | 电源 | 5V×2, GND×3, 3.3V_SYS×2, 3.3V_IO |
| 9-22 | MIPI CSI | 4-lane差分 + I2C + GPIO（摄像头） |
| 23-38 | MIPI DSI | 4-lane差分 + I2C + PWM（显示屏） |
| 39-44 | USB 2.0 | VBUS, D+, D-, ID（仅USB 2.0） |
| 45-52 | UART | 调试串口 + 蓝牙串口 |
| 53-58 | I2C | I2C1/I2C3/I2C4 |
| 59-66 | SPI | SPI0 + SPI2 |
| 67-78 | GPIO | 可复用PWM/UART/SPI/I2S |
| 79-80 | ADC/PMIC | SARADC + 电源管理中断 |

### 结构设计（10cm紧凑型）

- **三明治分层结构**：顶层外设 + 中层核心板电源 + 底层传感器
- **尺寸**：95mm × 85mm × 30mm，重量约350g
- **10个可插拔模块**：摄像头、显示屏、按键、WiFi、天线、陀螺仪、麦克风、电池、USB、核心板
- **散热**：自然对流，无需风扇（典型功耗7W，框架热阻3°C/W）

## 核心知识点

### 1. 理想二极管OR-ing原理

LTC4412通过检测SENSE和VIN引脚电压差来控制MOSFET：
- 当SENSE > VIN + 20mV：认为辅助源（USB）电压更高，切换到USB
- 当SENSE < VIN - 30mV：认为主源（电池）电压更高，切换到电池
- GATE控制主路径MOSFET（Q2），STAT控制辅助路径MOSFET（Q1）
- 470k反馈电阻确保STAT高阻态时Q1栅极被拉到SENSE电压，可靠关断

### 2. 升压电路设计要点

TPS61022反馈电阻计算：`VOUT = 1.0V × (1 + R7/R8)`
- 目标5V：R7=400kΩ, R8=100kΩ
- 原理图错误：R7误标为732kΩ（会输出8.32V，损坏器件）

SY8113反馈电阻计算：`VOUT = 0.8V × (1 + R9/R11)`
- 目标3.28V：R9=62kΩ, R11=20kΩ
- 原理图错误：R9误标为47kΩ, R11误标为30kΩ（会输出2.05V）

### 3. 充电电路设计

TP4056充电电流设置：`ICHG = 1000 / RPROG(mA)`
- RPROG=2kΩ → 充电电流500mA
- R18=0.1Ω为电流检测电阻，必须靠近BAT引脚
- 充电指示LED通过CHRG引脚驱动，低电平点亮

### 4. 设计演进关键教训

| 版本 | 问题 | 结论 |
|------|------|------|
| v3.2 BQ25895 | NVDC架构需I2C配置OTG模式 | 启动死锁：I2C需要5V，5V需要I2C |
| v5.0 TPS63020 | 3V输入时仅1.5A | 电流不足，弃用 |
| v5.1 LTC4412 | 发现官方Figure 2 | 单芯片控制双路，成本降至￥30.5 |

### 5. RV1126B重要约束

- **USB仅支持2.0**（480Mbps），尽管部分文档声称支持USB 3.0
- 芯片仅有1×DRD + 1×HOST USB 2.0接口
- 高速数据传输需通过千兆以太网实现

### PCB布局关键规则

```
大电流走线宽度：
├─ VBUS_5V路径：≥20mil
├─ VBAT_5V路径：≥20mil
├─ VCC5V0_SYS路径：≥20mil
└─ VCC3V3_SYS路径：≥15mil

MIPI差分对要求：
├─ 差分阻抗：100Ω ±10%
├─ 长度匹配：Lane内5mil，Lane间20mil
└─ 参考平面：完整地平面，不得跨越分割
```

### 原理图修正清单（必须执行）

```
R7:  732kΩ → 400kΩ  (P0, 否则输出8.32V损坏器件)
R9:  47kΩ  → 62kΩ   (P0, 否则输出2.05V系统不工作)
R11: 30kΩ  → 20kΩ   (P0, 同上)
C11: 新增 100nF      (P1, LTC4412 SENSE引脚滤波)
```

### 测试验证关键指标

```
USB单独供电：VCC5V0 = 4.95V, VCC3V3 = 3.3V
电池单独供电：VCC5V0 = 4.85V, VCC3V3 = 3.3V
无缝切换：切换时间<10μs，电压波动<100mV，核心板不重启
充电电流：500mA ±10%
充电截止：4.2V ±0.05V，电流<50mA
```
