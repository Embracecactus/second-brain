## 特色芯片深度推荐

### WCH 沁恒 RISC-V 家族
- 生态: [[wch]] — MounRiver IDE + WCH-LinkE(¥23) + 官方 SDK, 有 Arduino 移植
- CH32V003 是最便宜 32 位 MCU (¥0.58) → 适合极限编程挑战
- CH32X035 **全国产唯一集成 USB-PD 3.0 的 MCU** → 很多人不知道

### ESP32 新家族
- [[esp32-c6-p4-h2]] — C6 四模通信 / H2 纯 Thread 节点 / P4 视觉+显示
- C6 支持 **WiFi CSI 人体感知** (无传感器, 利用 WiFi 信号检测呼吸/心跳/手势)
- P4 需配 C6 才有 WiFi, 但有 MIPI-DSI/CSI, 是乐鑫首颗 MPU 级芯片

### RP2350 双架构异构
- Cortex-M33 + RISC-V hazard3 可并行运行
- PIO 状态机可模拟任意数字时序(替代 PCA9685/CPLD)
- 安全启动 + OTA 升级, ¥26 起步
- 相关: [[rp2350-pico2]]
