# 方向 4: 复古 / 音频 / 玩具

> 复古计算机复刻、开源硬件玩具、合成器/乐器、掌机/PDA 等冷门创意

---

## 💡 项目 1: CH32V003 ¥5 复古迷你游戏机 (2KB 极限编程)

**脑洞:** 只要 ¥4.29 的 V003 开发板 + ¥7 的 0.96" OLED(SSD1306, 128x64), 实现经典小游戏(贪吃蛇/Tetris/打砖块/Flappy Bird)。核心挑战在 **2KB SRAM + 1KB 可用帧缓冲**下塞进完整游戏逻辑: 每帧 128x64/8=1KB 缓冲就占了可用 RAM 的一半。省掉双缓冲、用单缓冲+位操作直接渲染。

**为什么没人做:** 多数掌机在 RP2040/RP2350/ESP32 上做。用 7 毛 RISC-V、2KB SRAM 做 mini 游戏机的几乎没有——因为 SRAM 太小、Flash 也小(16KB), 大部分人对这个配置的第一反应是"不可能"。

**核验稀缺度:** ⭐⭐⭐ — 没人用 2KB SRAM 做游戏机

**预算:** V003 开发板 ¥4.29 + OLED ¥7 + 按键/电池 ¥2 = **¥13**

**芯片推荐:** [[wch|CH32V003]] (¥0.58 的挑战平台)

## 💡 项目 2: RP2350 异构双核 PDA 复刻

**脑洞:** RP2350 双核异构(M33 + RISC-V)的天然分工: M33 核跑 MicroPython/显示/触控 UI(类 Palm Pilot), RISC-V 核裸跑 GPIO 轮询 + 键盘扫描 + 电源管理。设计复古 PDA 外形 + 机械键盘 + 240x320 TFT + SD 卡存储。

**为什么稀罕:** [[Pico Pal]] 等复古掌机已有人用 RP2350 做, 但大多只跑一个核或做纯游戏机。**异构双核分工的架构**——M33 跑高抽象层框架、RISC-V 裸跑底层 I/O 隔离——这没人专门做过, 且 RP2350 是第一个在两个核上能同时跑独立程序的双架构 MCU。

**核验稀缺度:** ⭐⭐ — PDA 概念不新但异构双核分工新

**预算:** Pico 2 ¥26 + 机械键盘 ¥15 + TFT ¥25 + SD 模块 ¥5 = **¥66**

**芯片推荐:** [[rp2350-pico2|RP2350]] (双架构异构 + PIO)

## 💡 项目 3: ESP32-P4 口袋触摸合成器

**脑洞:** P4 的 MIPI-DSI 驱动圆屏 LCD 显示器 + I2S 音频输出 + 电容触摸, 做一个口袋调频合成器/采样器。P4 的双核分工: LP 核(低功耗核)做待机/电源管理 + 触摸检测, HP 核(400MHz)做实时音频合成 + 波形生成。可以用触摸键盘弹奏、调参数。

**为什么稀罕:** 很多 ESP32 做合成器(Mozzi/ESP32-AudioI2S), 但用 ESP32-P4 的 MIPI-DSI + 双核分工做交互式触摸屏合成器的几乎没有——P4 是 2025 年才铺货的新芯片, 玩的人本来就少, 拿来做音频交互的更少。

**核验稀缺度:** ⭐⭐

**预算:** P4 核心板 ¥42.9 + MIPI 圆屏 ¥40 + I2S DAC ¥10 = **¥93**

**芯片推荐:** [[esp32-c6-p4-h2|ESP32-P4]] (MIPI-DSI + 双核 HP/LP + I2S)
