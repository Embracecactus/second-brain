## 💡 项目 1: CH32V203 百元内双路 SimpleFOC 驱动板

**脑洞:** 用 ¥2.65 的 CH32V203 替代 STM32/ESP32 做 SimpleFOC 双路 BLDC 驱动器。V203 有 144MHz, 硬件 MCPWM(电机专用 PWM), ADC 同步采样, SPI(接磁编码器 AS5600)。全线国产、成本压低到极致。双路 FOC 电流环控制两个云台电机。

**为什么稀罕:** SimpleFOC 主控几乎只用 STM32/ESP32。CH32V203 有同样外设(MCPWM+ADC)却 ¥2.65, 但几乎无人移植过 SimpleFOC 到 WCH 平台——官方有 MounRiver IDE 和 GCC 支持, 所以技术上可行, 只是没人去干。

**核验稀缺度:** ⭐⭐⭐ — CH32 + SimpleFOC 组合未见开源

**预算:**
| 项 | 价格 |
|---|---|
| CH32V203 芯片 | ¥2.65 |
| AS5600 磁编码器 x2 | ¥20 |
| 立创打板 + 元器件 | ¥20 |
| 云台电机 x2 | ¥30 |
| **合计** | **≈ ¥72** |

**芯片推荐:** [[wch|CH32V203]] (144MHz, MCPWM + ADC 同步采样)

**关键参考:**
- [SimpleFOC 中文官网](https://simplefoc.cn/)
- [灯哥开源 FOC 双路控制器 (ESP32)](https://github.com/ToanTech/Deng-s-foc-controller)
- [[wch]] — 沁恒开发环境

## 💡 项目 2: ESP32-C6 Wi-Fi CSI 手势识别 → 无接触舵机控制

**脑洞:** 结合方向1的 CSI 人体感知, 做一个**WiFi 信号手势控制**: 挥左手→舵机左转, 挥右手→右转, 推手→前进。完全无摄像头、无接触、无专用传感器。比超声波/红外/ToF 的体验高一大截, 且可以穿墙。

**核验:** Wi-Fi CSI 的手势识别论文很多(北大张大庆团队), 但**落地到控制一个实物的端到端开源项目不存在**——几乎所有论文都是可视化 demo, 没人真的用它去推舵机/开灯/转电机。

**核验稀缺度:** ⭐⭐⭐ — 端到端控制实物未见

**预算:** ESP32-C6 ¥16 + 舵机 ¥10 = **¥26** (¥100 预算内极低成本)

**芯片推荐:** [[esp32-c6-p4-h2|ESP32-C6]] (WiFi6 CSI 信号质量更好)

## 💡 项目 3: RP2350 PIO 驱动微型双足/四足 (双核异构分工)

**脑洞:** RP2350 的 **PIO 状态机**模拟 8-12 路舵机 PWM 时序, **双核异构**让 Cortex-M33 核跑姿态/逆运动学算法, RISC-V 核做 I/O 调度和传感器轮询——双架构并行协同, PIO 解放 CPU 的全部定时器资源。

**为什么稀罕:** RP2350 的 PIO 模拟舵机时序是 2024-2025 新玩法(传统用 PWM 定时器或 PCA9685), 但 PIO 更灵活、不占定时器。用双核异构分工(M33 算 + RV I/O)做微型足式机器人的, 目前未见开源项目——大部分 RP2350 项目只用了一个核, 或者用 PIO 做屏驱动而非舵机。

**核验稀缺度:** ⭐⭐

**预算:**
| 项 | 价格 |
|---|---|
| Pico 2 (RP2350) | ¥26 |
| 迷你 SG90 舵机 x8 | ¥40 |
| 3D 打印壳体 | ¥20 |
| **合计** | **≈ ¥86** |

**芯片推荐:** [[rp2350-pico2|RP2350]] (PIO 是独有优势, 双核异构是加分项)
