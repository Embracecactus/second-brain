# AX650N - YOLOv5 目标检测模型训练与部署

## 项目概述

本项目基于 YOLOv5（含 YOLOv5s 标准版与 YOLOv5-Lite 轻量版）进行目标检测模型的训练、导出与边缘部署，目标硬件平台为 AX650N 嵌入式芯片及树莓派。项目包含完整的数据准备、模型训练、ONNX 导出与推理测试流程。

## 技术栈

| 类别 | 技术 |
|------|------|
| 深度学习框架 | PyTorch 2.5.0, torchvision |
| 目标检测模型 | YOLOv5s v7.0, YOLOv5-Lite |
| 模型推理 | ONNX Runtime |
| 数据格式 | VOC (XML) -> YOLO (TXT) |
| 图像处理 | OpenCV, Pillow |
| 容器化 | Docker (Ubuntu 22.04) |
| 部署平台 | AX650N 芯片, 树莓派 |
| 训练环境 | GPU (CUDA) / CPU |

## 架构与关键设计

### 数据流水线

```
原始图片 + XML标注 (VOC格式)
  -> xml2txt.py / voc2yolov5.py (格式转换)
  -> pilt_train_valid.py (train/val/test 划分: 70%/20%/10%)
  -> YOLO 数据集目录结构 (images/ + labels/)
  -> safehat.yaml / mydata.yaml (数据集描述文件)
```

### 模型部署流程

```
PyTorch 训练 (.pt)
  -> export.py (导出 ONNX)
  -> ONNX Runtime 推理 (CPU/嵌入式设备)
  -> 后处理 (NMS) + 可视化
```

## 核心知识点

### 1. VOC 到 YOLO 标签转换原理

VOC 使用 `(xmin, xmax, ymin, ymax)` 绝对坐标，YOLO 使用 `(x_center, y_center, width, height)` 归一化坐标。转换公式：

```python
x = (xmin + xmax) / 2.0 / img_width
y = (ymin + ymax) / 2.0 / img_height
w = (xmax - xmin) / img_width
h = (ymax - ymin) / img_height
```

### 2. YOLOv5-Lite Anchor 配置

```python
stride = [8., 16., 32.]  # 三个检测层的步长
anchors = [
    [10, 13, 16, 30, 33, 23],      # 小目标
    [30, 61, 62, 45, 59, 119],     # 中目标
    [116, 90, 156, 198, 373, 326]  # 大目标
]
# 模型输入尺寸: 320x192 (YOLOv5-Lite) / 640x640 (YOLOv5s)
```

### 3. ONNX 推理后处理

模型输出需要经过 anchor 解码与 NMS 后处理：

```python
def cal_outputs(outs, nl, na, model_w, model_h, anchor_grid, stride):
    # 将模型原始输出解码为实际坐标
    # outs[:, 0:2] = (outs[:, 0:2] * 2 - 0.5 + grid) * stride  # 中心坐标
    # outs[:, 2:4] = (outs[:, 2:4] * 2) ** 2 * anchor_grid      # 宽高
```

### 4. PyTorch 2.6+ 兼容性问题

PyTorch 2.6 默认启用 `weights_only=True`，需手动设置为 `False`：

```python
# train.py 中修改
ckpt = torch.load(weights, map_location=device, weights_only=False)

# datasets.py 中修改
cache, exists = torch.load(cache_path, weights_only=False), True
```

同时 `np.int` 已弃用，需替换为 `int` 或 `np.int32`。

### 5. Docker 共享内存配置

训练时 DataLoader 多进程需要足够共享内存，否则报错：

```bash
docker run -it --shm-size="15g" -v /home/:/home/ ubuntu22-yolov5-lite:dahua /bin/bash
```

### ONNX 推理核心流程

```python
import onnxruntime as ort

session = ort.InferenceSession("best.onnx")
input_name = session.get_inputs()[0].name

# 预处理: resize + normalize + CHW
img = cv2.resize(frame, [model_w, model_h])
blob = np.expand_dims(np.transpose(img, (2, 0, 1)), axis=0).astype(np.float32) / 255.0

# 推理
outputs = session.run(None, {input_name: blob})[0].squeeze(axis=0)

# 后处理: anchor 解码 + NMS
boxes, confs, ids = post_process_opencv(outputs, model_h, model_w, img_h, img_w, thred_nms=0.4, thred_cond=0.5)
```

## 构建/运行方法

### 1. Docker 环境构建

```bash
cd AX650N_yolov5s
docker build -t ubuntu22-yolov5-lite:dahua .
docker run -it --shm-size="15g" -v /home/:/home/ ubuntu22-yolov5-lite:dahua /bin/bash
```

### 2. YOLOv5s 训练 (安全帽检测)

```bash
# 数据准备
cd VOC2028 && python3 voc2yolov5.py && cd .. && python3 pilt_train_valid.py

# 训练
python3 train.py --weights weights/yolov5s.pt --cfg models/yolov5s.yaml \
    --data data/safehat.yaml --epochs 150 --batch-size 16 --multi-scale --device 0
```

### 3. YOLOv5-Lite 训练 (交通场景)

```bash
python3 train.py --weights v5lite-s.pt --cfg models/v5Lite-s.yaml \
    --img-size 320 --batch-size 16 --data data/mydata.yaml --device 0/cpu
```

### 4. 模型导出 ONNX

```bash
python3 export.py --weights runs/train/exp17/weights/best.pt \
    --img-size 320 320 --include onnx --dynamic --simplify
```

### 5. ONNX 推理测试

```bash
# 图片检测
python3 detect.py --weights best.onnx --source test.jpg

# 视频检测 (YOLOv5-Lite)
python3 yolov5lite_test.py  # 输出 output.avi
```

### 6. 树莓派部署

```bash
python3 -m venv yolov5lite
source yolov5lite/bin/activate
pip3 install onnxruntime==1.19.0 opencv-python
python3 yolov5lite_test.py
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| `torch.load` weights_only 报错 | 设置 `weights_only=False` |
| `np.int` 弃用警告 | 替换为 `int` 或 `np.int32` |
| Docker 共享内存不足 | `--shm-size="15g"` |
| 标注越界 | `voc_label.py` 中添加边界修正 |
| 标注工具版本 | `pip install labelme==3.16.7` |
