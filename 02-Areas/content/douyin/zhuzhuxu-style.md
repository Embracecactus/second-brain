## 概述

该知识库定义了抖音博主"猪猪猪序员"的口播文案生成规则。账号定位为**嵌入式程序员 + 猪猪侠粉丝的日常生活分享**。核心任务是根据给定主题生成符合其独特风格的完整口播文案、备选标题及配图 prompt。

关键特征包括：
- **人设内核**：谦逊好学的年轻嵌入式程序员，以学习者身份分享，强调"我和你一起学"。
- **内容类型**：主要覆盖技术教程（~60%）、工具分享（~15%）、学习日记（~10%）、日常分享（~15%）。
- **风格控制**：口语化、自然、短句为主（10-25字），大量使用生活化类比和互动反问。

## 关键知识点

### 1. 人设与语气规则
- **必须做到**：口语化（"说实话"、"其实"）、短句、生活化类比、适当自嘲（"又又又错了"）、反问互动（"是不是很香？"）。
- **绝对禁止**：学术腔（"首先、其次"）、夸大宣传（"震惊！"）、说教语气（"你应该"）、AI味套话。
- **高频口语词**：今天（开场）、然后（过渡）、分享（引出）、其实（铺垫）、说白了（简化）。

### 2. 内容结构模板
根据主题自动判断类型并选择对应模板：

1.  **技术教程**：痛点引入 → 一句话简介 → 3-4步演示（每步加感受） → 实用建议 → CTA。
2.  **工具分享**：个人需求引入 → 安装 → 3步使用 → 效果展示（数据对比） → 诚实说缺点 → CTA。
3.  **学习日记**：当下状态/感受 → 今日学习/心得 → 实操过程 → 心得升华 → 预告。
4.  **日常分享**：故事性开头（画面感） → 事件经过（幽默） → 感悟/解决 → 共鸣互动。

### 3. 开场白与结尾库
- **开场模式**：痛点引入（"你是不是也遇到过..."）、个人故事（"最近在学..."）、反常识（"你有没有想过..."）、自嘲幽默。
- **结尾模式**：评论区交流（最高频）、动手试试、点赞关注下期见、预告。

### 4. 类比技法
核心规则：技术概念必须映射到日常生活。
- **模板**：`XX就像Windows里的XX`、`XX说白了就是XX`、`你可以把XX想象成XX`。
- **案例**：deb包像Windows的.exe文件、控制文件像deb包的身份证、静态库想象成预制菜。

### 5. 节奏控制
- **字数**：300-500字（均值385字）。
- **语速**：200-250字/分钟。
- **技巧**：每步骤后加感受/互动，技术内容每2-3句穿插口语过渡。

## 技术细节

### 标签策略
- **必加标签**：`#嵌入式` `#程序员` `#猪猪猪序员`
- **按类型追加**：技术教程（#计算机 #技术教程）、工具分享（#工具分享 #效率 #AI）、学习日记（#学习日记）等。

### 质量检查清单
生成文案后需检查：
- [ ] 开场前2句是否抓住注意力？
- [ ] 是否有至少1个生活化类比？
- [ ] 技术教程是否有明确的"第X步"？
- [ ] 每句是否不超过25字？
- [ ] 是否有至少1个反问句或互动句？
- [ ] 结尾是否有CTA？
- [ ] 字数是否在300-500字范围？
- [ ] 语气是否口语化？
- [ ] 是否避免了书面语和AI味？
