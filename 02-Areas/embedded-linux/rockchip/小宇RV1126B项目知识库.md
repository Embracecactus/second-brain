# 小宇RV1126B项目知识库

## 项目概述

本项目基于 **Rockchip RV1126B** SoC，由**小宇智联**设计的 IPC（网络摄像机）主板方案，型号为 **IPC50**。RV1126B 是一颗四核 Cortex-A53 处理器，集成 NPU、ISP，面向智能安防、AI 摄像机等场景。项目使用明远智客（MYZR）的 SDK 及开发板作为参考平台，基于 Linux 6.1 内核，支持 AMP（非对称多处理）架构，即 Linux AP + RT-Thread MCU 协同运行。

### 硬件组成

| 模块 | 关键器件 | 说明 |
|------|---------|------|
| 主板 | RV1126B + IPC50 | 小宇智联设计，含核心板与底板 |
| 摄像头模组 | IMX307 / IMX335 / IMX415 | 三种 Sensor 可选，MIPI CSI 接口 |
| HDMI IN | RK628D + F | HDMI 输入采集模组 |
| 屏幕 | GC9503V 3.97寸 IPS / GT911 触摸 | DSI 接口，含 FPC 转接板 |
| WiFi 模组 | A880S-D40L (AIC8800) | WiFi 6 2.4G/5G + BLE |
| 镜头 | YT12011 5MP + IR-CUT | 含红外切换机构 |
| 连接器 | 1.25mm / 1.0mm / 2.0mm 间距 | 多种 Wafer 接口 |

## 关键知识点

### 1. SDK 基本信息

- **SDK 版本**: `rv1126b_linux6.1_release_v1.1.0_20250920_sync20251107`
- **内核版本**: Linux 6.1.118
- **Bootloader**: U-Boot (Rockchip 定制)
- **OS**: Buildroot (Linux)
- **MCU**: RT-Thread (RISC-V 核)
- **解压方式**: 分卷合并后解压

```bash
cat rv1126b_linux6.1_release_v1.1.0_.tar.gz.part-* > rv1126b_linux6.1_release_v1.1.0_.tar.gz
tar xvf rv1126b_linux6.1_release_v1.1.0_.tar.gz
```

### 2. 板级配置文件位置

| 配置项 | 路径 |
|--------|------|
| Buildroot defconfig | `device/rockchip/.chips/rv1126b/OK1126B_S_buildroot_defconfig` |
| Linux DTS | `kernel-6.1/arch/arm64/boot/dts/rockchip/myzr-rv1126b-evb.dtsi` |
| Linux defconfig | `kernel-6.1/arch/arm64/configs/OK1126B-S-linux_defconfig` |
| U-Boot defconfig | `u-boot/configs/myzr_rv1126b_defconfig` |
| U-Boot DTS | `u-boot/arch/arm/dts/rv1126b-evb.dts` |
| MCU ITS 打包文件 | `device/rockchip/.chips/rv1126b/amp_mcu.its` |

### 3. AMP 架构 (非对称多处理)

RV1126B 支持 AMP 模式，Linux AP 与 MCU (RT-Thread RISC-V) 并行运行：

- **AP 核**: Quad Cortex-A53, 运行 Linux 6.1
- **MCU 核**: RISC-V, 运行 RT-Thread RTOS
- **共享内存**: RPMSG 通信机制, base=`0x48c3c000`, size=`0x40000`
- **MCU 加载地址**: `0x48c02000` (entry `0x48c02200`)

### 4. 实时性补丁 (PREEMPT_RT)

针对 Linux 6.1.118 内核的 RT 补丁链（需按顺序应用）：

```bash
# 补丁应用顺序 (在 kernel-6.1 目录下)
patch -p1 < 0001-patch-6.1.99-rt36-on-rockckip-base-5c295c763974.patch
patch -p1 < 0002-sched-isolation-remove-HK_FLAG_TICK-for-nohz_full-fo.patch
patch -p1 < 0003-mm-Kconfig-remove-selection-of-MIGRATION-for-CMA-to-.patch
patch -p1 < 0004-ARM-configs-add-rockchip_rt.config-for-PREEMPT_RT.patch
patch -p1 < 0005-arm64-configs-optimize-latency-for-PREEMPT_RT.patch
patch -p1 < 0006-phy-rockchip-inno-usb2-Fix-DEBUG_LOCKS_WARN_ON-in-ch.patch
```

> [!warning] 注意
> 如果出现 `The next patch would create the file arch/arm/configs/rockchip_rt.config, which already exists! Assume -R? [n]`，输入 `n`。

## 技术细节

### 1. U-Boot 编译体系

#### 启动流程

```
BootROM → MiniLoader(TPL/SPL) → TRUST(BL31/BL32) → U-Boot → Linux Kernel
```

#### INI 配置文件体系

| 维度 | TRUST.ini | MINIALL.ini |
|------|-----------|-------------|
| 所在目录 | `rkbin/RKTRUST/` | `rkbin/RKBOOT/` |
| 核心产物 | `trust.img` (安全启动镜像) | `loader.bin` (MiniLoaderAll) |
| 作用阶段 | BL31/BL32 安全固件 | TPL/SPL 硬件初始化 |
| 包含内容 | ARM Trusted Firmware, OP-TEE | DDR 初始化, MiniLoader, USB Plug |
| 使用工具 | `trust_merger` | `boot_merger` |

#### 编译命令

```bash
./build.sh uboot
```

#### defconfig 中添加自定义 INI

```sh
# u-boot/configs/myzr_rv1126b_defconfig 中添加
CONFIG_LOADER_INI="RV1126BMINIALL_FASTBOOT.ini"
CONFIG_TRUST_INI="RV1126BTRUST_MCU.ini"
```

#### 不同启动模式的配置

| 场景 | defconfig | Loader INI | Trust INI |
|------|-----------|------------|-----------|
| 常规 eMMC 启动 | `rv1126_defconfig` | `RV1126MINIALL.ini` | `RV1126TOS.ini` |
| 快速启动 (Thunder Boot) | `rv1126-emmc-tb.config` | `RV1126MINIALL_EMMC_TB.ini` | `RV1126TOS_TB.ini` |
| SPI Nor Flash 启动 | `rv1126-spi-nor.config` | `RV1126MINIALL_SPI_NOR.ini` | `RV1126TOS_SPI_NOR.ini` |

#### 快速启动关键配置项

```sh
CONFIG_SPL_KERNEL_BOOT=y          # 开启快速开机
CONFIG_SPL_BLK_READ_PREPARE=y     # 开启预加载
CONFIG_SPL_MISC_DECOMPRESS=y      # 开启解压功能
CONFIG_ROCKCHIP_THUNDER_BOOT=y    # Thunder Boot 支持
```

### 2. MCU (RT-Thread) 编译

#### 编译步骤

```bash
# 安装依赖
sudo apt install scons

# 进入 MCU 工程目录
cd rtos/bsp/rockchip/rv1126b-mcu

# 配置
scons --useconfig=board/rv1126b_evb1/defconfig
scons --genconfig

# 编译
scons -j16
```

#### 打包方式

**方法1: 独立 amp.img**

```bash
# 将 rtthread.bin 以 FIT 格式打包
./mkimage.sh amp
# 输出: amp.img
# 烧录到 amp 分区
```

**方法2: 打包到 uboot.img**

```bash
cp rtthread.bin ../../../../rkbin/bin/rv11/rtthread.bin
```

#### amp_mcu.its 配置详解

```dts
/dts-v1/;
/ {
    description = "FIT source file for rockchip AMP";
    images {
        hpmcu {
            data         = /incbin/("rtt.bin");
            type         = "standalone";
            arch         = "arm";  // Actually RISC-V, but U-Boot only accepts arm/arm64
            load         = <0x48c02000>;
            entry        = <0x48c02200>;
            compile {
                size     = <0x0003a000>;
                sys      = "rtt";        // "hal" or "rtt"
                rtt_config = "board/rv1126b_evb1/defconfig";
                core     = "mcu";        // "mcu" or "ap"
                rtt_exec = "prebuilts/gcc/linux-x86/riscv64/xpack-riscv-none-embed-gcc-10.2.0-1.2/bin/";
                cc       = "prebuilts/gcc/linux-x86/riscv64/xpack-riscv-none-embed-gcc-10.2.0-1.2/bin/riscv-none-embed-";
            };
        };
    };
    share {
        rpmsg_base  = <0x48c3c000>;
        rpmsg_size  = <0x00040000>;
    };
};
```

> [!note] 关键参数
> - `arch = "arm"` 是 U-Boot 的限制，实际 MCU 为 RISC-V 架构
> - `load = 0x48c02000` MCU 代码加载到 SRAM 的地址
> - `rpmsg_base = 0x48c3c000` AP 与 MCU 共享内存通信基地址

### 3. 设备树 (DTS) 配置

#### 主 DTS 结构

```dts
#include "OK1126B-S-common.dtsi"
#include "OK1126B-S-camera.dtsi"
#include "OK1126B-S-display.dtsi"
#include "rv1126b-amp.dtsi"

/ {
    model = "Forlinx OK1126B-S Board";
    processor = "Rockchip RV1126B (Quad core Cortex A53)";
    compatible = "rockchip,rv1126b-evb1-v10", "rockchip,rv1126b";

    chosen {
        bootargs = "earlycon=uart8250,mmio32,0x20810000 console=ttyFIQ0 rw root=PARTUUID=614e0000-0000 rootfstype=ext4 rootwait snd_soc_core.prealloc_buffer_size_kbytes=16 coherent_pool=32K";
    };
};
```

#### FIQ Debugger (串口调试)

```dts
&fiq_debugger {
    compatible = "rockchip,fiq-debugger";
    rockchip,serial-id = <0>;
    rockchip,wake-irq = <0>;
    rockchip,irq-mode-enable = <1>;
    rockchip,baudrate = <1500000>;  /* Only 115200 and 1500000 */
    interrupts = <GIC_SPI 240 IRQ_TYPE_LEVEL_HIGH>;
    status = "okay";
};
```

> [!warning] 波特率问题
> fiq_debugger 中波特率和 U-Boot 不一致可能导致串口驱动加载失败。RV1126B 仅支持 `115200` 和 `1500000` 两种波特率。

### 4. 常见问题排查

| 问题 | 解决方法 |
|------|---------|
| OV5695 摄像头不显示 | 将 `ov5695_default_default.json` 和 `ov5695_dphy2-ov5695_default.json` 复制到 `buildroot/output/rockchip_rv1126b/target/etc/iqfiles` 目录后重新编译镜像 |
| NPU 未使能 | 修改 `myzr-rv1126b-evb1.dtsi` 中 `&pwm0_8ch_0` 节点的 `status` 从 `"disabled"` 改为 `"okay"` |
| MCU 加载失败 | 检查 `devmem 0x48c02000` 和 `devmem 0x48c02200` 确认代码是否正确加载到 SRAM |
| 串口无输出 | 确认 fiq_debugger 波特率与 U-Boot 一致 |

### 5. MCU 代码区域验证

```bash
# 检查 MCU 代码是否正确加载到 SRAM
devmem 0x48c02000    # MCU 代码起始地址
devmem 0x48c02200    # MCU 入口地址
```

### WiFi 模组

- **型号**: A880S-D40L
- **芯片**: AIC8800D
- **规格**: WiFi 6 (802.11ax), 2.4GHz + 5GHz 双频, BLE
- **Linux SDK**: `aic8800d_linux_sdk_V4.0_2025_0410`
- **发布时间**: 2025.09.15

### 屏幕方案

- **当前使用**: GC9503V 驱动 IC, 3.97寸 IPS, DSI 接口, 型号 ZH040IA-05A
- **触摸 IC**: GT911 (Goodix)
- **备用方案**: 8寸屏 ZS080NH3103E3H7II-A (原计划, 无触摸)

### 镜头与 IR-CUT

- **镜头**: YT12011-5MP + IR0780 (500万像素, 红外截止波长 780nm)
- **IR-CUT**: ZR-A-16A, 2.4V 驱动, 20欧线圈电阻, K98 镜片
