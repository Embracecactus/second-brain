# RK3528 嵌入式 Linux SDK 开发笔记

## 项目概述

本项目基于 LubanCat (鲁班猫) 提供的 Rockchip RK3528 Linux Generic SDK，包含完整的 bootloader (U-Boot)、Linux kernel、根文件系统 (Debian/Ubuntu) 构建体系，用于 RK3528 SoC 平台的嵌入式 Linux 系统开发。SDK 版本为 LubanCat_Linux_Generic_SDK_20260114。

## 技术栈

| 组件 | 技术细节 |
|------|----------|
| **SoC** | Rockchip RK3528, ARM Cortex-A53 (ARMv8/AArch64) |
| **Bootloader** | U-Boot 2017.09 (Rockchip 定制版), 支持 FIT Image |
| **ATF (ARM Trusted Firmware)** | BL31 (EL3 Runtime), BL32 (OP-TEE) |
| **Kernel** | Linux 5.10 (默认), 6.1 (可选) |
| **Root Filesystem** | Debian 11/12 (Bullseye/Bookworm), Ubuntu 20.04/22.04 |
| **桌面环境** | GNOME, XFCE, Lite (无桌面) |
| **交叉编译工具链** | GCC-Linaro 6.3.1 (aarch64-linux-gnu / arm-linux-gnueabihf) |
| **DDR** | DDR3 / DDR4 / LPDDR4X, 频率 1056MHz |
| **打包格式** | FIT Image (Flattened Image Tree), GPT 分区 |

## 架构与关键设计

### 启动流程

```
BootROM -> DDR Init (TPL) -> SPL -> ATF (BL31) -> U-Boot -> Linux Kernel
```

- **IDB (Initial Device Block)**: BootROM 从存储介质加载的第一段代码，由 DDR 初始化 bin + SPL 合并而成
- **MiniLoaderAll.bin**: DDR bin + USBPlug + SPL 合并后的 loader，用于 RKDevTool 烧录
- **uboot.img**: FIT 格式，包含 U-Boot + BL31 + TEE (OP-TEE) + DTB
- **boot.img**: FIT 格式，包含 Kernel + DTB + Resource (logo 等)

### 固件组成

```
update.img (最终升级固件)
├── MiniLoaderAll.bin    # Bootloader Loader (DDR + SPL)
├── uboot.img            # FIT Image (U-Boot + ATF + TEE)
├── boot.img             # FIT Image (Kernel + DTB + Resource)
└── rootfs.img           # 根文件系统 (ext4)
```

### 分区布局 (parameter-extboot.txt)

```
CMDLINE: mtdparts=
  0x00004000@0x00004000(uboot)
  0x00040000@0x00008000(boot:bootable)
  -@0x00048000(rootfs:grow)
```

GPT 分区方案，rootfs 分区支持自动扩展。

### FIT Image 签名

boot.its 中定义了 SHA256 + RSA2048 签名机制：
- 签名算法: `sha256,rsa2048`
- 填充方式: `pss`
- 签名组件: `fdt`, `kernel`, `multi` (resource)
- 密钥提示: `dev`

## 核心知识点

### 1. SDK 目录结构

| 目录 | 说明 |
|------|------|
| `Lubancat/` | 主 SDK 目录，通过 repo 管理 |
| `Lubancat/device/rockchip/rk3528/` | 板级配置 (defconfig, parameter, boot.its) |
| `Lubancat/kernel-5.10/` | Linux 5.10 内核源码 |
| `Lubancat/kernel-6.1/` | Linux 6.1 内核源码 (可选) |
| `Lubancat/u-boot/` | U-Boot 源码 |
| `Lubancat/debian11/`, `debian12/` | Debian 根文件系统构建 |
| `Lubancat/ubuntu20.04/`, `ubuntu22.04/` | Ubuntu 根文件系统构建 |
| `Lubancat/tools/linux/` | Linux 平台烧录/打包工具 |
| `Lubancat/output/firmware/` | 构建输出的固件文件 |
| `1.uboot/` | 独立编译的 U-Boot 工程 |
| `rkbin/` | Rockchip 二进制固件仓库 (DDR bin, SPL, BL31, TEE) |

### 2. RK3528 Boot 二进制文件命名规则

格式: `[chip]_[module]_[feature]_[version].[postfix]`

示例: `rk3528_spl_loader_v1.11.106.bin`
- `v1.11`: DDR 版本号
- `106`: SPL 版本号 (v1.06 去掉点号)

### 3. 板级 Defconfig 体系

LubanCat SDK 使用分层 defconfig:
- `rockchip_defconfig` -> 基础 Rockchip 配置
- `LubanCat_rk3528_*_defconfig` -> 板级 + 系统配置
  - `_debian_gnome`: Debian + GNOME 桌面
  - `_debian_xfce`: Debian + XFCE 桌面
  - `_debian_lite`: Debian 精简版 (无桌面)
  - `_ubuntu_gnome/xfce/lite`: Ubuntu 变体

### 4. U-Boot 关键配置

- 平台: `CONFIG_ROCKCHIP_RK3528=y`, `CONFIG_TARGET_EVB_RK3528=y`
- 架构: ARM64 (AArch64), `CONFIG_ARM64=y`
- FIT Image: `CONFIG_ROCKCHIP_FIT_IMAGE=y`, `CONFIG_ROCKCHIP_FIT_IMAGE_PACK=y`
- SPL 支持: MMC, SPI Flash, SPI, MTD, Crypto
- 安全启动: Android AVB, FIT HW Crypto, FIT Image Post Process

### 5. 内核关键配置

- `CONFIG_LOCALVERSION="-rk3528"`
- `CONFIG_ARCH_ROCKCHIP=y`
- 支持 cgroup v2, BPF, namespace, uclamp 调度
- 设备树: `rk3528-lubancat-generic.dts` (通用), `rk3528-lubancat-q1.dts` (Q1 开发板)

## 重要代码片段

### U-Boot 构建脚本核心流程 (make.sh)

```bash
# 工具链选择: 优先使用外部 CROSS_COMPILE, 否则使用 prebuilts
CROSS_COMPILE_ARM64=../prebuilts/gcc/linux-x86/aarch64/gcc-linaro-6.3.1-2017.05-x86_64_aarch64-linux-gnu/bin/aarch64-linux-gnu-

# 芯片信息选择: 从 .config 中解析 CONFIG_ROCKCHIP_RKxxxx
CHIP_PATTERN='^CONFIG_ROCKCHIP_[R,P][X,V,K][0-9ESXB]{1,5}'

# 打包流程: 根据 PLAT_TYPE 选择 FIT / DECOMP / 传统模式
# FIT 模式: pack_fit_image (u-boot.img = U-Boot + ATF + TEE)
# 最终输出: uboot.img, trust.img, loader.bin
```

### Loader INI 配置 (RK3528MINIALL.ini)

```ini
[CODE471_OPTION]
Path1=bin/rk35/rk3528_ddr_1056MHz_v1.11.bin    # DDR 初始化

[CODE472_OPTION]
Path1=bin/rk35/rk3528_usbplug_v1.04.bin        # USB 烧录插件

[LOADER_OPTION]
FlashData=bin/rk35/rk3528_ddr_1056MHz_v1.11.bin  # DDR bin (TPL)
FlashBoot=bin/rk35/rk3528_spl_v1.06.bin           # SPL

[OUTPUT]
PATH=rk3528_spl_loader_v1.11.106.bin              # 合并输出
```

### 固件打包清单 (package-file-extboot)

```
# NAME          PATH
package-file    package-file

bootloader      MiniLoaderAll.bin
uboot           uboot.img

```

## 构建/运行方法

### 环境准备

```bash
# 解压 SDK (约 3.6GB)
cd /home/lijian/project/rk3528
tar xzf LubanCat_Linux_Generic_SDK_20260114.tgz
```

### 全量构建 (通过 SDK Makefile)

```bash
cd Lubancat/

# 查看支持的目标
make help

# 选择 defconfig (例如 Debian 精简版)
make LubanCat_rk3528_debian_lite_defconfig

# 可选: 修改配置
make menuconfig

# 构建 (日志保存在 output/log/)
make

# 输出固件: output/firmware/update.img
```

### 单独编译 U-Boot

```bash
cd 1.uboot/

# 配置
./make.sh rk3528_defconfig

# 编译 + 打包 (自动生成 uboot.img, trust.img, loader)
./make.sh

# 子命令
./make.sh loader    # 仅打包 loader
./make.sh trust     # 仅打包 trust.img
./make.sh uboot     # 仅打包 uboot.img
```

### 烧录

```bash
# 使用 RKDevTool (Windows) 或 upgrade_tool (Linux) 烧录
# Linux 工具位于: Lubancat/tools/linux/Linux_Upgrade_Tool/

# 或使用 rkflash.sh 脚本
cd Lubancat/
./rkflash.sh
```
