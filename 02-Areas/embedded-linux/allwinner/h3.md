## 项目概述

基于 Allwinner H3 SoC 的完整嵌入式 Linux 系统构建项目，涵盖从底层 SCP 固件（crust-firmware）、U-Boot 引导加载程序、Linux 内核到根文件系统的全栈定制，并包含 AR100 协处理器固件动态切换内核模块和 Jailhouse 虚拟化支持。

## 技术栈

| 层次 | 组件 | 版本/说明 |
|------|------|-----------|
| SCP 固件 | crust-firmware | OpenR1K (or1k-linux-musl) 编译，运行于 AR100 协处理器 |
| 引导加载程序 | U-Boot | v2026.01，ARM 架构，SPL 模式 |
| Linux 内核 | mainline Linux | v6.19，ARM 32-bit |
| 根文件系统 | ext4 | 自定义构建 |
| 虚拟化 | Jailhouse | 基于 ARM 的分区虚拟化（含 orangepi0 配置） |
| 交叉编译器 | gcc-arm-11.2 | arm-none-linux-gnueabihf |
| SCP 编译器 | or1k-linux-musl | OpenR1K 架构专用 |
| 打包工具 | genimage | 磁盘镜像生成 |

## 架构与关键设计

### 启动流程

```
BootROM -> SPL (U-Boot) -> U-Boot -> Linux Kernel -> rootfs
              |
              +-> SCP (crust-firmware -> AR100 协处理器)
```

### 目录结构

```
h3/
├── 0.crust-firmware/    # SCP 固件，运行于 AR100 (OpenR1K 核心)
├── 1.uboot/             # U-Boot v2026.01，含 SPL
├── 2.kernel/            # Linux v6.19 主线内核
├── 3.rootfs/            # 根文件系统
├── 4.modules/           # 外部内核模块（AR100 固件切换器）
├── jailhouse/           # Jailhouse 虚拟化 hypervisor
├── linux-5.10/          # 旧版内核（备用）
├── pack/                # genimage 打包配置
├── tools/               # 交叉编译工具链
└── readme/              # 项目文档
```

### 设备树设计 (DTS)

基于 `sun8i-h3.dtsi`，定制板级 DTS (`sun8i-h3-system.dts`)，关键外设配置：
- **UART0**: 调试串口 115200n8
- **EMAC**: 内部 MII PHY 以太网
- **HDMI**: 输出 + CEC
- **USB**: 4x EHCI/OHCI + OTG
- **MMC0**: SD 卡 (4-bit)
- **SY8106A**: CPUX 电压调节器 (1.0V-1.3V, I2C @ 0x65)
- **LED**: 电源绿灯 (PL10) + 状态红灯 (PA15)
- **IR**: 红外接收

## 核心知识点

### 1. AR100 协处理器与 SCP 固件

H3 内置 AR100 OpenR1K 核心作为系统控制处理器 (SCP)，负责电源管理、休眠唤醒等。crust-firmware 为其提供开源固件实现。

关键硬件地址：
- **SRAM A2**: `0x00040000` (48KB) -- AR100 固件加载目标
- **R_CPUCFG**: `0x01F01C00` -- AR100 复位控制寄存器（安全模式可访问）

### 2. ARMv7 TrustZone 与安全模式

R_CPUCFG 寄存器属于安全世界 (Secure World)，非安全模式下无法直接访问。U-Boot 需配置为安全启动模式：

```
CONFIG_ARMV7_BOOT_SEC_DEFAULT=y
# CONFIG_ARMV7_PSCI is not set   # 关键：禁用 PSCI 以保留 AR100 控制权
CONFIG_SMP=y
```

### 3. SMP 多核启动问题

启用 `CONFIG_ARMV7_PSCI` 会导致 `smp_kick_all_cpus()` 被跳过，系统只识别 1 个 CPU。解决方案是禁用 PSCI，使用传统 SMP 启动方式。

### 4. 固件加载流程 (scp_switch 模块)

```
stop AR100 (写 0 到 R_CPUCFG)
    -> memcpy_toio 固件到 SRAM A2
    -> flush_cache_all
    -> start AR100 (写 1 到 R_CPUCFG)
    -> 等待就绪
```

## 重要代码片段

### AR100 复位控制

```c
// 停止 AR100: 写 0 到 R_CPUCFG (assert reset)
static int ar100_stop(void)
{
    writel(0x00000000, r_cpucfg_base);
    udelay(100);
    return 0;
}

// 启动 AR100: 写 1 到 R_CPUCFG (de-assert reset)
static int ar100_start(void)
{
    writel(0x00000001, r_cpucfg_base);
    udelay(100);
    return 0;
}
```

### SRAM 映射与固件写入

```c
#define SRAM_A2_BASE  0x00040000
#define SRAM_A2_SIZE  0xC000   // 48KB

// 使用 write-combining 映射
sram_a2_base = ioremap_wc(SRAM_A2_BASE, SRAM_A2_SIZE);

// 写入固件
memcpy_toio(sram_a2_base, fw_buf, fw_size);
flush_cache_all();
```

### sysfs 接口设计

模块创建 `/sys/class/ar100_scp/ar100_scp/` 节点：
- `path` (RW): 固件路径
- `status` (RO): 当前固件状态
- `sram_info` (RO): 硬件地址信息
- `reload` (WO): 重新加载当前固件
- `switch_fw` (WO): 切换到新固件

### genimage 磁盘布局

```
image my.img {
    hdimage { disk-signature = 0x12345678 }
    partition u-boot {
        in-partition-table = false
        image = "u-boot-sunxi-with-spl.bin"
        offset = 8K
        size = 40M
    }
    partition rootfs {
        partition-type = 0x83
        image = "rootfs.ext4"
        size = 4000M
    }
}
```

## 构建/运行方法

### 环境准备

```bash
export PATH=$PWD/tools/gcc-arm-11.2-2022.02-x86_64-arm-none-linux-gnueabihf/bin:$PATH
```

### 0. 编译 SCP 固件

```bash
cd tools && tar -zxvf or1k-linux-musl-cross.tgz
export PATH=$PWD/or1k-linux-musl-cross/bin:$PATH
cd 0.crust-firmware
make CROSS_COMPILE=or1k-linux-musl- system_h3_defconfig
make CROSS_COMPILE=or1k-linux-musl- -j32 scp
```

### 1. 编译 U-Boot

```bash
cd 1.uboot
make ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabihf- system_h3_defconfig
make ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabihf- -j32
```

### 2. 编译内核

```bash
cd 2.kernel
make ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabihf- system_h3_defconfig
make ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabihf- -j32
# 安装模块到 rootfs
make ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabihf- INSTALL_MOD_PATH=../3.rootfs modules_install
```

### 3. 编译外部模块

```bash
cd 4.modules
make ARCH=arm CROSS_COMPILE=arm-none-linux-gnueabihf-
```

### 4. 打包镜像

```bash
cd pack
genimage --input input --output image --config root/genimage.cfg
```

### 使用 scp_switch 模块

```bash
insmod scp_switch.ko
echo "/lib/firmware/scp.bin" > /sys/class/ar100_scp/ar100_scp/switch_fw
cat /sys/class/ar100_scp/ar100_scp/status
echo "reload" > /sys/class/ar100_scp/ar100_scp/reload
```
