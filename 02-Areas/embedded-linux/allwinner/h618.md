# Allwinner H618 TV Box 定制 Linux 系统

## 项目概述

本项目为基于全志 H618 SoC 的 TV Box 构建完整的定制嵌入式 Linux 系统，涵盖从 ARM Trusted Firmware (ATF)、U-Boot 引导加载器、Linux 内核到基于 Ubuntu Jammy 的根文件系统的全链路构建流程，并在此基础上探索 Jailhouse 分区化 Hypervisor 移植与 LinuxCNC 工业控制应用适配。

## 技术栈

- **SoC**: Allwinner H618 (sun50i_h616 系列, ARM Cortex-A53, ARMv8/AArch64)
- **Bootloader**: ARM Trusted Firmware (BL31) + U-Boot (sun50i-h618-ai-tv_defconfig)
- **Linux Kernel**: 6.18.0 (含大量 megi/orangepi 社区补丁与 Armbian 补丁)
- **根文件系统**: Ubuntu Jammy (22.04) arm64, 基于 debootstrap 构建, 桌面环境为 ubuntu-desktop-minimal
- **交叉编译工具链**: gcc-arm-11.2-2022.02-x86_64-aarch64-none-linux-gnu (GCC 11.2)
- **打包工具**: genimage (生成最终磁盘镜像)
- **虚拟化**: Jailhouse v0.12 分区化 Hypervisor (移植中)
- **应用层**: LinuxCNC (CNC 控制), Docker/RetroArch (游戏模拟器)
- **补丁来源**: [megi linux orange-pi-6.18 分支](https://codeberg.org/megi/linux/src/branch/orange-pi-6.18), Armbian build 框架

## 关键设计决策

### 1. 分阶段编译流程 (pack.sh)

整个系统采用顺序编译, 各阶段严格依赖:

1. **ATF 编译** → 生成 BL31 固件, 导出环境变量 `BL31`
2. **U-Boot 编译** → 引用 BL31, 生成 `u-boot-sunxi-with-spl.bin`
3. **Kernel 编译** → 独立编译内核与模块
4. **RootFS 构建** → 安装内核模块, 拷贝 Image/DTB, 制作 ext4 镜像
5. **打包** → genimage 将 U-Boot 写入镜像偏移 8K 处

### 2. 根文件系统四阶段构建 (3.rootfs/Makefile)

采用 debootstrap 标准三阶段 + 自定义第四阶段:

- **firststage**: debootstrap `--foreign` 下载基础包
- **secondstage**: chroot 内执行 debootstrap 二阶段
- **thirdstage**: chroot 内安装桌面环境 (ubuntu-desktop-minimal)、配置用户/时区/网络
- **fourthstage**: 拷贝内核/DTB/boot.scr, 配置 APT 源

### 3. 内核补丁策略 (patch.sh)

内核基于上游 6.18, 应用约 570+ 补丁, 来源分类:
- `patches.megous/`: megi 社区补丁 (驱动优化、HDMI audio、Type-C、摄像头等)
- `patches.drm/`: DRM/显示引擎重构 (DE33 mixer、H616 TCON-TV、HDMI PHY)
- `patches.media/`: 视频编解码 (cedrus AFBC、H265 硬解)
- `patches.backports/`: 6.19-rc1 回移补丁
- `patches.armbian/`: Armbian 社区补丁 (网络、音频、MMC、GPU Mali)

### 4. Jailhouse 分区化虚拟化探索

项目包含 Jailhouse Hypervisor 移植教程, 目标是在 H618 上实现:
- Root Cell 运行 Linux (管理功能)
- 非 Root Cell 运行裸机 RTOS (实时任务)
- 通过 EL2 硬件虚拟化实现 CPU/内存/中断的静态分区隔离

### 5. 启动流程

```
ROM → SPL (ATF BL1/BL2) → BL31 → U-Boot → boot.scr → Linux Kernel → rootfs
```

U-Boot boot.scr 脚本通过 PARTUUID 定位根分区:
```
setenv bootargs "console=ttyS0,115200 root=PARTUUID=${partuuid} rootfstype=ext4 rw rootwait"
booti ${kernel_addr_r} - ${fdt_addr_r}
```

## 核心代码片段

### genimage.cfg - 磁盘镜像布局
```
image my.img {
    hdimage {
        disk-signature = 0x12345678
    }
    partition u-boot {
        in-partition-table = false
        image = "u-boot-sunxi-with-spl.bin"
        offset = 8K
        size = 40M
    }
}
```
U-Boot SPL 位于偏移 8K 处, 不参与分区表, 符合 Allwinner FEL/启动 ROM 的加载规范。

### 根文件系统 Makefile 关键配置
```makefile
HOSTNAME := h618-tv-box
ROOTFS_TYPE := jammy
ARCH := arm64
ROOTFS_UUID := 614e0000-0000-4b53-8000-1d28000054a9
HAS_DESKTOP := y
```

## 构建与运行

### 环境准备
```bash
# 安装依赖
sudo apt-get install qemu qemu-user-static binfmt-support debootstrap genimage
# 设置交叉编译工具链 PATH
export PATH=$PWD/tools/gcc-arm-11.2-2022.02-x86_64-aarch64-none-linux-gnu/bin:$PATH
```

### 全流程编译
```bash
cd h618-tv-box
./pack.sh
```

### 分步构建根文件系统
```bash
cd 3.rootfs
make env          # 安装构建依赖
make firststage   # debootstrap 第一阶段
make secondstage  # debootstrap 第二阶段
make thirdstage   # 安装桌面环境与系统配置
make boot_scr     # 编译 U-Boot 启动脚本
make fourthstage  # 拷贝内核/DTB, 配置 APT 源
make mkrootfsext4 # 生成 ext4 根文件系统镜像
```

### 烧录
最终镜像位于 `pack/images/my.img`, 使用 `dd` 或 Etcher 烧录至 SD 卡/eMMC。

## 关键知识点

1. **Allwinner H618 与 H616 共享 SoC 平台标识** `sun50i_h616`, ATF 编译使用 `PLAT=sun50i_h616`, 但 U-Boot 和 Kernel 使用 `sun50i-h618` defconfig, 需注意区分。
2. **debootstrap 跨架构构建**依赖 `qemu-user-static` + `binfmt-support`, 在 x86_64 主机上模拟 AArch64 执行环境。
3. **Ubuntu 22.04+ 使用 deb822 格式** (`.sources` 文件) 替代传统 `sources.list`, 但本项目通过 fourthstage 强制覆盖为传统格式以确保兼容性。
4. **megi 社区内核分支**是 Allwinner 平台最重要的第三方内核维护源, 提供了 HDMI、GPU Mali、WiFi/BT、摄像头等大量上游缺失的驱动支持。
5. **Jailhouse Hypervisor** 不同于 KVM/Xen, 采用静态分区模型, 无调度器, 无资源过量分配, 非常适合嵌入式实时场景。
6. **genimage** 工具用于精确控制磁盘镜像布局, 支持指定偏移量、分区表类型等, 是嵌入式 Linux 打包的标准工具。
