## 二、2026 年嵌入式六大趋势

1. **AI-Native 设计** — MCU+NPU 成标配，先从模型出发再搭硬件
2. **RISC-V 从备选变主流** — 中国政策要求 2027 年所有 IoT 芯片必须用 RISC-V
3. **Chiplet 芯粒架构下沉** — 60% 嵌入式 SoC 采用模块化拼接
4. **边缘 GenAI** — 端侧跑量化大模型（1B-7B 参数级别）
5. **物理 AI** — 感知→决策→执行完整闭环（机器人/自动驾驶）
6. **国产全链路替代** — MCU/驱动 1:1 替代 STM32，RT-Thread 替代 FreeRTOS

## 三、重点芯片深度解析

### Nordic nRF54H20 — 下一代 BLE 旗舰
- **架构**: 双 Cortex-M33@320MHz + 多个 RISC-V 协处理器（各自优化特定工作负载）
- **内存**: 2MB NV + 1MB RAM，远超同类 BLE SoC
- **无线**: BLE 5.4 + LE Audio + Thread + Matter + 802.15.4，Rx 灵敏度 -100dBm
- **安全**: PSA Certified Level 3，抗侧信道攻击加密加速器，篡改传感器
- **外设**: USB 480Mbps + CAN FD + 2×I3C + 14-bit ADC + NFC
- **功耗**: Rx 电流比 nRF5340 降 50%，适合耳机/可穿戴持续接收场景
- **定位**: VR/AR 控制器、LE Audio 耳机、工业 IoT、Matter 智能家居

### ST STM32N6 — 首款带 NPU 的 STM32
- **CPU**: Cortex-M55@800MHz（Arv8.1-M + Helium DSP 扩展）
- **NPU**: Neural-ART Accelerator@1GHz，600 GOPS，3 TOPS/W 能效比
- **内存**: 4.2MB 嵌入式 SRAM（最大 STM32），128KB TCM 实时数据
- **多媒体**: NeoChrom 2.5D GPU + H.264 硬编码(1080p15/720p30) + ISP(5MP@30fps)
- **相机**: MIPI CSI-2 + 并行接口，支持 MIPI/DCIM 传感器
- **安全**: TrustZone + SESIP Level 3 + PSA Level 3 目标
- **特殊**: **无片上 Flash**，外接 PSRAM/SDRAM/NOR/NAND
- **性能对比**: YOLO 人脸检测比 STM32H747 快 **75 倍**，比 STM32MP1(A7@800MHz) 推理快 **25 倍**
- **定位**: 边缘 AI 视觉、智能工业相机、AR 眼镜（Meta Bounds 已采用）

### ST ST64UWB — 下一代 UWB 测距雷达芯片
- **架构**: Cortex-M85@100-256MHz + UWB + NBA 辅助无线
- **标准**: IEEE 802.15.4ab（新一代）+ 802.15.4z（兼容），比 4z 测距距离提升 **8 倍**
- **工艺**: 18nm FD-SOI，链路预算比 bulk CMOS 高 3dB，额外延长 50% 距离
- **雷达**: A500 型号支持多运动目标检测、距离/角度感知、踢感、儿童存在检测(CPD)
- **安全**: SESIP Level 3 安全飞地，片上保护数字钥匙凭证
- **三款型号**:
  - A100: 汽车数字钥匙 + 车辆定位，ASIL A(B)
  - A500: 汽车 + AI 加速雷达（CPD/踢感/泊车传感器）
  - C100: 消费/工业，Aliro 智能锁兼容
- **定位**: 汽车数字钥匙、儿童存在检测、智能门锁、资产追踪

### Microchip SAM L21 — 超低功耗标杆
- **CPU**: Cortex-M0+@48MHz，2.46 CoreMark/MHz
- **功耗**: 活跃 35μA/MHz，睡眠 **200nA**（ULPMark 410 分，同级最高）
- **技术**: SleepWalking 外设（睡眠中自主响应事件）、静态/动态电源门控
- **外设**: USB 2.0 FS + 6×SERCOM + 12-bit ADC + AES + 触摸控制器(PTC)
- **内存**: 最高 256KB Flash + 40KB SRAM
- **封装**: 32/48/64 pin，TQFP/QFN/WLCSP
- **定位**: 纽扣电池 IoT 节点、可穿戴、医疗贴片、环境监测

## 四、还没烂大街的有趣项目方向

### A. 基于新芯片特性（趁还没人做）

#### 1. RP2350 RISC-V 模式 + HSTX → HDMI 显示设备
- Pico 2 切到 RISC-V Hazard3 核心，用 HSTX 直接输出 DVI/HDMI
- 做 **硬币大小的复古游戏机** 或 **迷你信息屏**
- 几乎无人用 RISC-V 模式做 HDMI 输出
- 芯片成本: ~$5 (Pico 2)

#### 2. CH32V307 千兆以太网 + USB HS → DIY 路由器/抓包器
- ¥15 的 RISC-V 芯片自带千兆 MAC + USB HS PHY + 8 路 UART
- 做 **RISC-V 核心的迷你路由器**、**网络抓包分析仪**、**串口服务器**
- 全网几乎没见人做过
- 芯片成本: ~¥15 (CH32V307)

#### 3. ESP32-P4 本地 H.264 编码 + MIPI CSI → 无线图传摄像头
- P4 是目前唯一能硬件 H.264 编码的 ESP 芯片
- 比 ESP32-S3 纯软件编码方案顺滑得多
- 做 Wi-Fi 6 无线摄像头或 **USB 摄像头采集卡**
- 芯片成本: ~$5-8

#### 4. BL616/BL618 全协议 Matter 桥接器（单芯片）
- 一颗芯片同时跑 Wi-Fi 6 + BLE + Zigbee + Thread + 以太网
- 做 **Home Assistant 多协议网关**
- 比 ESP32-C6 多一个以太网口，但几乎没人做
- 芯片成本: ~$3-5

#### 5. TI MSPM0C1104（1.38mm²）极致微缩项目
- 比米粒还小，比芝麻略大
- 适合做 **一次性医疗传感器**、**智能耳内设备**
- 能手工焊接这芯片本身就是挑战
- 封装: 晶圆级 WCSP，需热风枪或回流焊

### B. 方向性创意（不限芯片）

#### 6. 磁悬浮 + 触摸交互装置
- 电磁铁控制物体悬浮 + 电容触摸感应交互
- 做 **悬浮的交互艺术装置**，不是普通钟表
- 技术点: PID 悬浮控制 + 触摸感应 + LED 效果

#### 7. 3D ToF 人体存在感应 + 行为分析
- ST **VL53L9CX** 新款 3D ToF LiDAR（5cm-9m，2.3K 分区）
- 检测房间内人体位置、数量、静止/移动，比 PIR 准得多
- 用于智能灯光、安防、老人跌倒检测

#### 8. NVMe over USB 自制固态 U 盘
- MCU + FPGA 或高速 MCU 实现 NVMe 协议转 USB
- 自制超高速 U 盘，兼具学习价值
- 技术点: NVMe 驱动、USB 3.0、FTL 算法

#### 9. FOC 电机控制 + TinyML 异常检测
- TI AM13Ex 或 NXP MCX A34x
- 运行时检测电机振动/电流，AI 预测轴承寿命
- 边缘 AI 预测性维护的迷你工业版

#### 10. 离线 AI 语音助手（完全本地不联网）
- ESP32-S3 或 Infineon PSoC Edge
- 本地跑唤醒词 + 命令识别 + TTS，无需网络
- **隐私友好的家庭语音控制**

#### 11. 老旧仪表 AI 智能升级
- 给老式万用表/示波器/水表加摄像头
- MCU 跑 TinyML OCR 识别读数，BLE 上传手机
- 让古董仪器变智能，成本极低

#### 12. RP2350 PIO 逻辑分析仪
- PIO 状态机从 RP2040 的 8 个增至 12 个
- 做 8 通道、100MSps 级别的低成本逻辑分析仪
- 技术点: PIO 编程、时序分析、PC 端上位机

### C. 符合 2026 政策风口

#### 13. 低空经济：飞控数据记录 + 坠机分析
- 2026 中国低空经济元年，eVTOL 热点
- 读取飞控日志，本地 AI 分析飞行姿态异常
- 芯片: STM32C5 / GD32 / CH32V307

#### 14. BMS 电池管理系统 + 云端分析
- 监测每节电池电压/温度，SOC/SOH 估算
- 电动车/储能是持续大热赛道
- 芯片: NXP MCX N94x / GD32F505 / TI BQ79826

#### 15. 全国产 RISC-V 工业控制器
- CH32V307 + RT-Thread + 国产驱动
- 替代西门子/三菱 PLC 的完全开源方案
- 成本: 硬件 <¥100，开源软件完全免费

### D. 新芯片特性驱动的项目（深度版）

#### 16. STM32N6 + NPU 本地 AI 人脸识别门禁
- Neural-ART 600GOPS 跑轻量化人脸检测/识别模型
- MIPI CSI 接摄像头，ISP 预处理，NPU 推理
- 不联网、不上传照片，**完全离线隐私门禁**
- 比树莓派方案功耗低 10 倍，成本更低
- 芯片: STM32N657（带 NPU 的型号）

#### 17. ST64UWB-C100 智能门锁（Aliro 协议）
- UWB 精确测距，手机靠近自动开锁，比 BLE 方案精确得多
- IEEE 802.15.4ab 8 倍距离提升，放在包里也能解锁
- SESIP Level 3 安全飞地保护数字钥匙
- 芯片: ST64UWB-C100（6×6mm QFN）

#### 18. Nordic nRF54H20 LE Audio 无线耳机
- 双 M33@320MHz + RISC-V 协处理器，处理音频编解码
- BLE 5.4 LE Audio + Auracast 广播音频
- 1MB RAM 足够跑高质量音频 DSP
- Rx 电流比 nRF5340 降 50%，续航翻倍
- 芯片: nRF54H20（模组 $5-8 级）

#### 19. SAM L21 环境能量采集传感器节点
- 35nA 睡眠 + SleepWalking，太阳能/热电/振动能量采集供电
- 10 年+ 电池寿命或完全无电池运行
- PTC 触摸按键 + 12-bit ADC 传感器采集
- BLE 模块（外挂 nRF52）低功耗上报
- 芯片: SAM L21（$1-2 级）

#### 20. ESP32-P4 + MIPI CSI 无人机视觉避障
- P4 双 RISC-V@400MHz + AI 指令 + H.264 硬编码
- MIPI CSI 接摄像头，本地跑轻量化光流/深度估计算法
- 比纯软件方案帧率高 3 倍，延迟低
- Wi-Fi 6 实时图传
- 芯片: ESP32-P4（$5-8 级）

#### 21. RP2350 RISC-V + PIO 软件定义无线电(SDR)
- 切到 RISC-V Hazard3 核心，PIO 做高速 ADC 采样
- 实现 MHz 级 SDR 接收机（FM/ADS-B/LoRa 解调）
- 几乎无人用 PIO 做 SDR，极具探索价值
- 芯片: Pico 2（~$5）

### E. 跨界创意 / 艺术 × 工程 × 科学

#### 22. UWB 雷达非接触生命体征监护仪
- ST64UWB-A500 或 NXP Trimension 做 UWB 雷达
- 单芯片同时测距+雷达，检测呼吸/心跳/体动，无需穿戴设备
- 比 PIR 准得多，比摄像头隐私友好
- 应用: 婴儿监护、老人跌倒检测、睡眠质量分析、ICU 无接触监护
- **技术壁垒**: UWB 雷达信号处理算法（CIR 信道冲激响应 + CNN 分类）
- 芯片: ST64UWB-A500 / NXP SR150

#### 23. ESP32-P4 + 激振器 → 悬浮粒子 3D 显示
- ESP32-P4 双 RISC-V@400MHz + MIPI DSI
- 控制磁悬浮装置 + 高速 LED，在空中绘制 3D 图案
- 类似 Holofan 但用磁悬浮而非旋转，更安静更酷
- 技术点: 磁场闭环控制 + 视觉暂留 + 无线同步
- 芯片: ESP32-P4（$5-8）

#### 24. RP2350 PIO → 复合视频信号生成器

### F. 极客实验 / 芯片极限探索

> 以下项目挖掘芯片的"隐藏能力"或"非典型用法"，每一条都需要深入阅读芯片手册 + 逆向思维。

#### 31. ESP32 隐蔽蓝牙后门逆向工程 (CVE-2025-27840)
- Tarlogic Security 在 RootedCON 2025 发现 ESP32 蓝牙固件中 **29 个未文档化 HCI 命令**
- 其中 0xFC02 命令可直接写入 RAM/Flash，无需认证
- 项目: 自制 C 语言 USB 蓝牙驱动 (BluetoothUSB)，枚举所有隐藏命令，验证每条命令的功能
- 可以做: MAC 地址伪装、LMP/LLCP 数据包注入、持久化后门植入演示
- **安全研究价值**: 影响全球 10 亿+ 设备，供应链安全活教材
- 芯片: ESP32（任何开发板 ~$3）

#### 32. RP2350 双架构安全攻防实验室
- RP2350 同时有 ARM Cortex-M33 和 RISC-V Hazard3 两套核心
- DEFCON 挑战赛已验证: 电压毛刺可禁用 ARM 核、让 RISC-V 核以完全调试权限运行
- 项目: 搭建完整攻防环境
  - 用 ChipWhisperer 做电压毛刺注入，复现 OTP 密钥提取
  - 激光故障注入 (OpenFlexure Delta Stage 改装，成本 <€1000)
  - 对比 ARM TrustZone vs RISC-V 安全模式的抗攻击差异
- **学术价值**: 双架构安全对比是全新研究方向，可发论文
- 芯片: Pico 2（~$5）+ ChipWhisperer-Nano（~$300）

#### 33. RP2040 PIO 驱动 VGA 显示器渲染 Mandelbrot 集
- PIO 生成精确 VGA 时序 (25.175MHz 像素时钟)，电阻 DAC 输出 RGB 模拟信号
- 一个 PIO 做 HSYNC/VSYNC，一个做像素输出，第三个做音频 (同时！)
- 双核 ARM 各算半屏 Mandelbrot，浮点 vs 定点对比渲染
- **已验证**: Hunter Adams 的 pico-vga 项目已实现 640×480@60Hz，8 色
- 进阶: 加入交互式缩放 (USB HID 鼠标控制)、分形动画、实时音频可视化叠加
- 芯片: Pico 2（~$5）+ 电阻 DAC + VGA 接口

#### 34. STM32-SDR: MCU 变身软件定义无线电
- 已有成熟开源项目 STM32-SDR (87 stars)，基于 STM32F4
- 进阶方案: ESP32 + TEF6686 汽车收音机芯片
  - TEF6686 灵敏度极高 (远超 RTL-SDR)，支持 FM/AM/短波/长波
  - ESP32 做信号处理 + 显示，Si5351 做本振
  - 成本 <$30，性能媲美 $200 的专业接收机
- **极客玩法**: 解码 AIS 船舶信号、气象卫星APT图像、LoRa信号嗅探
- 芯片: ESP32 + TEF6686 模块 + Si5351

#### 35. AS7341 光谱传感器 → 艺术品鉴定/修复辅助
- AS7341: 11 通道光谱 (350-1000nm)，6 个独立 16-bit ADC 并行采集

- **跨界价值**: 博物馆/拍卖行/收藏家的低成本鉴定工具
- 芯片: AS7341 模块（~$20）+ Arduino/ESP32

### G. 前沿融合 / 多技术交叉

> 以下项目融合 2-3 种前沿技术，产生 1+1+1 >> 3 的化学反应。每一条都是可以发论文或做产品原型的方向。

#### 41. Darśana: Pico 2 上的专业级 64 旋钮虚拟模拟合成器
- **已验证项目** (Hackaday.io, 2025.10): RP2350 上跑 5 声道复音合成器
- 64 个物理旋钮 + 32 个按钮，零菜单，全部参数实时可调
- 每个声道: 3 个振荡器 + 噪声 → 饱和 OSC 混音器 → TPT/ZDF 梯形滤波器 (自激振荡)
- 48kHz/24-bit I2S 立体声输出，DMA 持续流式传输
- RP2350 超频到 250MHz，一个核心跑 DSP，另一个跑控制/UI
- 用到: PIO(I2S) + DMA + SPI(ADC×4, 按钮扩展×2) + FRAM(预设存储) + OLED
- **震撼点**: $6 MCU 上的专业级触感合成器，音色可比肩 $2000 硬件合成器
- 参考: github.com/raybellis/PicoSynth (128 声道, 16 通道多音色)
- 芯片: Pico 2（~$5）+ PCM5122 DAC + 64× 电位器

#### 42. 24GHz 雷达手势识别: 无摄像头、无穿戴、无光环境下的空中手势控制
- **已有验证** (efecagatay/Radar-Gesture-Recognition-TinyML): STM32 + HLK-LD2410C
- 24GHz FMCW 雷达检测手部微动，Doppler 频移 + 能量变化提取特征
- TinyML (TFLite Micro) 在 Cortex-M4 上跑 CNN 分类: 左挥/右挥/握拳/张开
- **已实现 >90% 准确率**，纯边缘推理，无云端依赖
- 进阶方向:
  - 换到 STM32N6 + NPU，用 600GOP 做更复杂的 3D 手势轨迹识别
  - 结合 UWB 雷达 (ST64UWB)，同时测距 + 手势，实现"靠近 + 手势"组合控制
  - 用 RP2350 的 PIO 做雷达信号预处理 (高速采样 + DMA)
- **应用**: 手术室无接触控制、工业机器人操控、车载手势交互
- 芯片: STM32F4/H7 或 STM32N6 + HLK-LD2410C (~$8)

#### 43. ESP32-S3 WiFi CSI 人体活动识别: 用 WiFi 信号"看"穿墙壁
- WiFi 信号在房间内传播时，人体移动会导致信道状态信息 (CSI) 变化
- ESP32-S3 可以采集 CSI 数据 (无需摄像头，无需穿戴设备)
- 在 MCU 上跑时序分类模型 (LSTM/CNN)，识别: 走/跌倒/坐/站/挥手
- **隐私友好**: WiFi 信号不会泄露人脸/身体细节，只有运动模式
- **已验证**: 多篇论文证明 WiFi CSI 可实现 >95% 活动识别准确率
- 进阶: 融合雷达 + CSI (多模态)，跨场景泛化
- **社会价值**: 老人跌倒检测 (不穿手环、不装摄像头)、智能家居无感控制
- 芯片: ESP32-S3（~$5）

#### 44. STM32N6 NPU 多模型级联: 手掌检测→关键点→手势分类 三阶段推理
- **已有项目** (profirst30/x-cube-n6-ai-hand-landmarks-gesture-classification)

  2. 手部 21 关键点检测模型 → MediaPipe 格式输出
  3. 自研关键点→手指计数算法 (几何启发式)
- **震撼点**: MCU 级别的多模型推理流水线，帧间推理 <50ms
- 进阶: 加入第三个模型做手势语义分类 (Rock/Paper/Scissors/OK/ThumbsUp)
- 或接入 NPU 加速的手写数字识别，实现"空中写字"
- **学术价值**: 多模型级联是边缘 AI 的前沿方向，可发论文
- 芯片: STM32N6570-DK（~$60）

#### 45. RP2040 精密频率计/信号发生器: $5 做到 6 位精度
- **已有项目** (jbentham/picofreq, 42 stars)

- 反向利用 PLL 配置: 精确合成任意频率 (如 6.78MHz NFC 载波)
- **极客玩法**:
  - 用 PIO 做 DDS (直接数字合成) 信号发生器，0.1Hz 步进
  - 频率计 + 信号发生器 + 逻辑分析仪 = $5 的完整测试仪器套件
  - GPS 校准后精度可达 10^-8 量级，媲美 $500 仪器
- **实用价值**: 电子工程师的便携调试工具，学校实验室的低成本替代
- 芯片: Pico 2（~$5）+ GPS 模块（~$5）
