## 二、2026 年嵌入式六大趋势

1. **AI-Native 设计** — MCU+NPU 成标配，先从模型出发再搭硬件
2. **RISC-V 从备选变主流** — 中国政策要求 2027 年所有 IoT 芯片必须用 RISC-V
3. **Chiplet 芯粒架构下沉** — 60% 嵌入式 SoC 采用模块化拼接
4. **边缘 GenAI** — 端侧跑量化大模型（1B-7B 参数级别）
5. **物理 AI** — 感知→决策→执行完整闭环（机器人/自动驾驶）
6. **国产全链路替代** — MCU/驱动 1:1 替代 STM32，RT-Thread 替代 FreeRTOS

## 三、重点芯片深度解析

### Nordic nRF54H20 — 下一代 BLE 旗舰
- **架构**: 双 Cortex-M33@320MHz + 多个 RISC-V 协处理器（各自优化特定工作负载）
- **内存**: 2MB NV + 1MB RAM，远超同类 BLE SoC
- **无线**: BLE 5.4 + LE Audio + Thread + Matter + 802.15.4，Rx 灵敏度 -100dBm
- **安全**: PSA Certified Level 3，抗侧信道攻击加密加速器，篡改传感器
- **外设**: USB 480Mbps + CAN FD + 2×I3C + 14-bit ADC + NFC
- **功耗**: Rx 电流比 nRF5340 降 50%，适合耳机/可穿戴持续接收场景
- **定位**: VR/AR 控制器、LE Audio 耳机、工业 IoT、Matter 智能家居

### ST STM32N6 — 首款带 NPU 的 STM32
- **CPU**: Cortex-M55@800MHz（Arv8.1-M + Helium DSP 扩展）
- **NPU**: Neural-ART Accelerator@1GHz，600 GOPS，3 TOPS/W 能效比
- **内存**: 4.2MB 嵌入式 SRAM（最大 STM32），128KB TCM 实时数据
- **多媒体**: NeoChrom 2.5D GPU + H.264 硬编码(1080p15/720p30) + ISP(5MP@30fps)
- **相机**: MIPI CSI-2 + 并行接口，支持 MIPI/DCIM 传感器
- **安全**: TrustZone + SESIP Level 3 + PSA Level 3 目标
- **特殊**: **无片上 Flash**，外接 PSRAM/SDRAM/NOR/NAND
- **性能对比**: YOLO 人脸检测比 STM32H747 快 **75 倍**，比 STM32MP1(A7@800MHz) 推理快 **25 倍**
- **定位**: 边缘 AI 视觉、智能工业相机、AR 眼镜（Meta Bounds 已采用）

### ST ST64UWB — 下一代 UWB 测距雷达芯片
- **架构**: Cortex-M85@100-256MHz + UWB + NBA 辅助无线
- **标准**: IEEE 802.15.4ab（新一代）+ 802.15.4z（兼容），比 4z 测距距离提升 **8 倍**
- **工艺**: 18nm FD-SOI，链路预算比 bulk CMOS 高 3dB，额外延长 50% 距离
- **雷达**: A500 型号支持多运动目标检测、距离/角度感知、踢感、儿童存在检测(CPD)
- **安全**: SESIP Level 3 安全飞地，片上保护数字钥匙凭证
- **三款型号**:
  - A100: 汽车数字钥匙 + 车辆定位，ASIL A(B)
  - A500: 汽车 + AI 加速雷达（CPD/踢感/泊车传感器）
  - C100: 消费/工业，Aliro 智能锁兼容
- **定位**: 汽车数字钥匙、儿童存在检测、智能门锁、资产追踪

### Microchip SAM L21 — 超低功耗标杆
- **CPU**: Cortex-M0+@48MHz，2.46 CoreMark/MHz
- **功耗**: 活跃 35μA/MHz，睡眠 **200nA**（ULPMark 410 分，同级最高）
- **技术**: SleepWalking 外设（睡眠中自主响应事件）、静态/动态电源门控
- **外设**: USB 2.0 FS + 6×SERCOM + 12-bit ADC + AES + 触摸控制器(PTC)
- **内存**: 最高 256KB Flash + 40KB SRAM
- **封装**: 32/48/64 pin，TQFP/QFN/WLCSP
- **定位**: 纽扣电池 IoT 节点、可穿戴、医疗贴片、环境监测

## 四、还没烂大街的有趣项目方向

### A. 基于新芯片特性（趁还没人做）

#### 1. RP2350 RISC-V 模式 + HSTX → HDMI 显示设备
- Pico 2 切到 RISC-V Hazard3 核心，用 HSTX 直接输出 DVI/HDMI
- 做 **硬币大小的复古游戏机** 或 **迷你信息屏**
- 几乎无人用 RISC-V 模式做 HDMI 输出
- 芯片成本: ~$5 (Pico 2)

#### 2. CH32V307 千兆以太网 + USB HS → DIY 路由器/抓包器
- ¥15 的 RISC-V 芯片自带千兆 MAC + USB HS PHY + 8 路 UART
- 做 **RISC-V 核心的迷你路由器**、**网络抓包分析仪**、**串口服务器**
- 全网几乎没见人做过
- 芯片成本: ~¥15 (CH32V307)

#### 3. ESP32-P4 本地 H.264 编码 + MIPI CSI → 无线图传摄像头
- P4 是目前唯一能硬件 H.264 编码的 ESP 芯片
- 比 ESP32-S3 纯软件编码方案顺滑得多
- 做 Wi-Fi 6 无线摄像头或 **USB 摄像头采集卡**
- 芯片成本: ~$5-8

#### 4. BL616/BL618 全协议 Matter 桥接器（单芯片）
- 一颗芯片同时跑 Wi-Fi 6 + BLE + Zigbee + Thread + 以太网
- 做 **Home Assistant 多协议网关**
- 比 ESP32-C6 多一个以太网口，但几乎没人做
- 芯片成本: ~$3-5

#### 5. TI MSPM0C1104（1.38mm²）极致微缩项目
- 比米粒还小，比芝麻略大
- 适合做 **一次性医疗传感器**、**智能耳内设备**
- 能手工焊接这芯片本身就是挑战
- 封装: 晶圆级 WCSP，需热风枪或回流焊

### B. 方向性创意（不限芯片）

#### 6. 磁悬浮 + 触摸交互装置
- 电磁铁控制物体悬浮 + 电容触摸感应交互
- 做 **悬浮的交互艺术装置**，不是普通钟表
- 技术点: PID 悬浮控制 + 触摸感应 + LED 效果

#### 7. 3D ToF 人体存在感应 + 行为分析
- ST **VL53L9CX** 新款 3D ToF LiDAR（5cm-9m，2.3K 分区）
- 检测房间内人体位置、数量、静止/移动，比 PIR 准得多
- 用于智能灯光、安防、老人跌倒检测

#### 8. NVMe over USB 自制固态 U 盘
- MCU + FPGA 或高速 MCU 实现 NVMe 协议转 USB
- 自制超高速 U 盘，兼具学习价值
- 技术点: NVMe 驱动、USB 3.0、FTL 算法

#### 31. ESP32 隐蔽蓝牙后门逆向工程 (CVE-2025-27840)
- Tarlogic Security 在 RootedCON 2025 发现 ESP32 蓝牙固件中 **29 个未文档化 HCI 命令**
- 其中 0xFC02 命令可直接写入 RAM/Flash，无需认证
- 项目: 自制 C 语言 USB 蓝牙驱动 (BluetoothUSB)，枚举所有隐藏命令，验证每条命令的功能
- 可以做: MAC 地址伪装、LMP/LLCP 数据包注入、持久化后门植入演示
- **安全研究价值**: 影响全球 10 亿+ 设备，供应链安全活教材
- 芯片: ESP32（任何开发板 ~$3）

#### 32. RP2350 双架构安全攻防实验室
- RP2350 同时有 ARM Cortex-M33 和 RISC-V Hazard3 两套核心
- DEFCON 挑战赛已验证: 电压毛刺可禁用 ARM 核、让 RISC-V 核以完全调试权限运行
- 项目: 搭建完整攻防环境
  - 用 ChipWhisperer 做电压毛刺注入，复现 OTP 密钥提取
  - 激光故障注入 (OpenFlexure Delta Stage 改装，成本 <€1000)
  - 对比 ARM TrustZone vs RISC-V 安全模式的抗攻击差异
- **学术价值**: 双架构安全对比是全新研究方向，可发论文
- 芯片: Pico 2（~$5）+ ChipWhisperer-Nano（~$300）

#### 33. RP2040 PIO 驱动 VGA 显示器渲染 Mandelbrot 集

| **目标售价** | $29–39 (对标 TP-Link Tapo AI Camera $49, Hikvision $59) |

**选片逻辑**:
- 双 RISC-V 芯片 = **真正免 ARM 授权费** 的 AI 相机方案
- BL808 100 GOPS NPU 跑 YOLOv8n @30fps, H.264 编码器压缩视频流, 64MB PSRAM 做大缓冲区
- ESP32-P4 负责 MIPI CSI 图像采集 + 千兆以太网/WiFi 6 双路视频传输 + MIPI DSI 本地预览
- 两片全 RISC-V 芯片, 完全开源 ISA, 无 ARM 锁喉风险

**功能矩阵**:
- **AI 对象检测**: NPU 运行 YOLOv8n/m, 检测人/车/动物, 目标跟踪
- **双视频流**: BL808 H.264 编码器输出主码流 (1080p@30fps) + 子码流 (QVGA@15fps)
- **双路传输**: ESP32-P4 千兆以太网 + WiFi 6 同时输出, 热备冗余
- **本地预览**: MIPI DSI 直接驱动 3.5" 屏幕, 现场查看无需 App
- **边缘存储**: BL808 录制定时/触发视频到 microSD + 64MB PSRAM 环形缓冲区

**技术挑战与方案**:
1. **双芯片通信** — BL808 SPI/QuadSPI 到 ESP32-P4, 或通过 PSRAM 共享; 带宽需求 15MB/s (H.264 1080p)
2. **NPU 模型部署** — Bouffalo Lab NPU SDK 适配 YOLOv8n, INT8 量化后 300KB 模型, 推理 <20ms
3. **H.264 编码延时** — BL808 硬件 H.264 编码 <1 帧延迟, 实时性优于软件编码
4. **双 RISC-V 调试** — 两片都需要 JTAG, OpenOCD + VSCode 双窗口调试

**竞品对比**: 主流 AI 相机使用 ARM SoC (海思 Hi3516EV300 或安霸 SoC), 受美国出口管制影响; RISC-V 方案完全自主可控, BOM 更低

**MVP 路线**: BL808 开发板 → MIPI CSI 摄像头驱动 → NPU YOLO 检测 → H.264 编码 → ESP32-P4 开发板 → 双芯片通信 → 以太网 RTSP 流 → WiFi 6 流 → 独立 4 层 PCB → FCC/CE 认证
